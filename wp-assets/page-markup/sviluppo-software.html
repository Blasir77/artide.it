Sviluppo software per case dell'acqua ed erogatori

Artide sviluppa il software che pilota le proprie case dell'acqua: firmware embedded, dashboard di telecontrollo case dell'acqua, applicazioni per le tessere RFID, integrazioni con i gestionali dei Comuni. Il software Artide governa la depurazione acqua, l'erogazione, la fatturazione elettronica e gli allarmi della casa dell'acqua. Tutto il codice è scritto e mantenuto in Italia, con aggiornamenti firmati e procedure di backup conformi ai requisiti ISO 22000.
